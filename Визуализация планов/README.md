### ✨ Можливості дашборду:
1. **🎬 16 Reels на місяць (4 на тиждень: Пн, Ср, Пт, Нд):** 
   - Інтерактивні чекбокси з прогрес-баром.
   - Фільтрація за 6 авторськими рубриками (*Дизайн без води, Помічаю те, чого не помічають, Бриф, який пішов не туди, Дизайн під мікроскопом, Зсередини проєкту, Дизайн і життя*).
   - Кнопка **«Сценарій ➔»** відкриває повну розкадровку (таймінг, дія, кадр, монтаж), текст озвучки, стиль зйомки та точний CTA.
2. **📱 Щоденна система Stories (Пн–Нд):** фокус кожного дня, структура ланцюжка та готові шаблони (*A/B голосування, WIP, розбір помилок, м'який продаж*).
3. **💼 Канбан робочих завдань:** управління клієнтськими замовленнями (*В черзі ➔ В роботі ➔ На узгодженні ➔ Готово*).
4. **📊 Аналітика, Формула сильного Reels & Банк наступних тем (15 ідей)** + швидкі нотатки з автозбереженням.
